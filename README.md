## Descripción
**TaskFlow** es una herramienta colaborativa diseñada para organizar, priorizar y dar seguimiento al progreso de las actividades diarias de un equipo de desarrollo.

## Funcionalidades
* Creación y gestión de nuevas tareas.
* Edición de información y estados.
* Filtrado por prioridades.

## Tecnologías Utilizadas
* **Frontend:** `HTML5`, `CSS3`, `JavaScript`
* **Control de versiones:** `Git` y `GitHub`

## Requisitos Previos
* Un navegador web moderno.
* Un editor de código (ej. *VS Code*).
